# X 内容生成器 / Information Radar

项目代号：123123

这是一个面向 X（Twitter）创作者的移动端一键推文生成器。核心不是做一个复杂的 Agent 平台，而是把成熟的开源信息采集、趋势分析、内容分析和生成经验组合成一个简单可靠的产品。

## 项目总目标

1. 每日自动采集信息。
2. 判断哪些消息是最新、重要、正在升温的。
3. 分析大家正在关心什么。
4. 分析用户自己的历史内容表现，形成个人化的平台表现模型。
5. 把“今天值得写什么”形成内容机会池。
6. 用户输入主题后，一键完成研究、推理、写作、去 AI 味和排版。
7. 最后按需要生成配图。

## 当前原则

- 先组合成熟开源方案，不重复造轮子。
- 先做最小可用闭环，再扩展。
- 每完成一个可验证阶段立即提交 Git。
- 仓库文档是项目的外部记忆。每次继续工作先读 PROJECT_STATE.md。
- 不把简单的推文生成过早设计成复杂 Agent。
- 不声称掌握 X 的精确推荐权重；平台分析以公开资料和用户自身历史数据为依据。
