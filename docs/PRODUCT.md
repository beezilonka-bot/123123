# 产品构思

## 1. 一句话

每天帮 X 创作者发现值得写的东西，并在用户需要时一键把它写成自己的推文。

## 2. 用户真正需要的不是“新闻阅读器”

信息分析器的最终输出不是一堆新闻，而是：

- 今天发生了什么？
- 哪些事情正在升温？
- 哪些事情和我的领域有关？
- 大家为什么在讨论？
- 哪些信息值得我写？
- 如果现在写，可以从什么角度切入？

因此信息雷达是内容生成器的内部能力，不是独立新闻产品。

## 3. 一键生成路径

用户输入：一个主题、一句话想法、一个链接，或直接选择“今日值得写”。

系统内部：

理解需求 → 读取个人风格 → 理解主题 → 必要时定向搜索 → 了解受众 → 筛选事实与观点 → 推理 → 写初稿 → 去 AI 味 → 编辑/排版 → 按需生成图片

## 4. 个人化资产

第一阶段不做复杂知识库，只保留真正有价值的东西：

- 个人写作风格
- 关注主题
- 目标受众
- 历史推文
- 历史表现数据
- 图片偏好

## 5. 信息分析器

每日采集后，为每个候选事件形成基础信号：

- freshness：新鲜度
- velocity：讨论/传播增长速度
- relevance：与用户主题相关度
- source_quality：来源质量
- discussion：讨论程度
- novelty：相对于已有信息的新颖度

这些信号用于排序和解释，不把它们伪装成 X 官方推荐权重。

## 6. 内容机会池

信息分析器最终产生：

事件 → 为什么重要 → 谁在关心 → 可写角度 → 适合的内容形式

这一步连接信息世界和创作世界。

## 7. MVP

最小闭环：

手机输入主题 → 后端研究 → LLM 生成 → 返回推文

第二个闭环：

每日信息采集 → 今日热点/机会 → 用户点击 → 一键生成

先让这两个闭环跑起来，再增加图片、自动发布、复杂分析。
