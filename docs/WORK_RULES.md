# 工作规则

## 每次开始工作

第一件事：

1. 读取 PROJECT_STATE.md
2. 检查当前 branch / commit
3. 查看当前阶段目标
4. 再开始工作

## 每次完成一个小阶段

必须：

1. 验证
2. commit
3. 更新项目状态
4. 再进入下一阶段

## 设计原则

- 简单优先
- 成熟开源优先
- 可替换组件优先
- 真实数据优先
- 能验证才实现
- 不提前建设复杂 Agent
- 不为了“架构完整”而增加无实际价值的模块

## 关于 X 推荐机制

只使用公开可验证资料和用户自己的历史数据。

不要把猜测写成官方权重。

## 关于上下文丢失

Git commit + PROJECT_STATE.md + ROADMAP.md 是项目的外部记忆。

如果上下文被截断，重新读取这三个文件即可恢复工作位置。
